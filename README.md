## 🚀 Core Modules

### 🧾 System Identity Engine (`script.sh`)
Establishes a baseline system fingerprint
- Kernel + distribution telemetry
- Runtime environment mapping
- Licensing awareness (GPL v2)
- User-space intelligence

```bash
bash script.sh
```

---

### 📦 FOSS Intelligence Layer (`script2.sh`)
Maps your system to the open-source universe
- Detects package ecosystems (RPM/DEB)
- Extracts kernel metadata
- Contextualizes major FOSS tools

```bash
bash script2.sh
```

---

### 🔐 Security & Permission Auditor (`script3.sh`)
Drives compliance visibility & risk detection
- Deep scan of critical directories
- Permission & ownership insights
- Disk usage intelligence

```bash
bash script3.sh
```

---

### 📊 Log Intelligence Engine (`script4.sh`)
Converts raw logs into decision-ready insights
- Pattern detection (error, warning, failed, etc.)
- Match aggregation & trend signals
- Tail-based contextual output

```bash
bash script4.sh /var/log/syslog error
```

---

### 📝 Open Source Manifesto Generator (`script5.sh`)
Humanizes technology through personal philosophy
- Interactive input model
- Auto-generated manifesto artifacts
- Timestamped identity output

```bash
bash script5.sh
```
